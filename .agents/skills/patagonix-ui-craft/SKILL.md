# Patagonix UI Craft Skill

1. Leer UX/UI y design system del pack.
2. Inspeccionar componentes existentes y reutilizar antes de duplicar.
3. Trabajar por pantalla: navegación, catálogo, producto, carrito, checkout, pedidos, admin.
4. Priorizar responsive real, semántica, foco y estados de interacción.
5. No inventar prestaciones, contenido comercial, precios, reviews o sellos de confianza.
6. No usar `div` clicable cuando corresponde button/link.
7. Añadir tests de comportamiento y capturas Playwright en tamaños clave.
8. Comparar visualmente antes/después y revisar que el diseño no degrade rendimiento.
