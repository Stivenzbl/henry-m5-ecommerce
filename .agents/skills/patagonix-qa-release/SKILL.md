# Patagonix QA & Release Skill

1. Leer `docs/08_QA_Y_RELEASE.md` y criterios de aceptación.
2. Ejecutar typecheck, unit tests, integration tests y build.
3. Ejecutar E2E de compra/admin en local o preview usando datos demo.
4. Probar 320/375/768/1024/1440 px, teclado, zoom 200% y reduced motion.
5. Revisar consola, red, errores y accesibilidad automatizada; complementar manualmente.
6. Registrar commit, entorno, navegador, fecha, comandos y resultados.
7. No desplegar producción sin consentimiento.
8. Si algún test falla, bloquear el release y reportar con evidencia.
